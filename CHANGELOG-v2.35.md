# Transcriber v2.35 — Compact editing tools and complete transcript copy

Find and Vet now share the main editing toolbar. Find is collapsed by default; click Find or press Ctrl/Cmd+F, then expand Replace only when needed. Escape closes Find. Vet opens a right panel with the existing local checks, team rules, suggestions, bulk preview, history and Undo.

Vet → Configure AI vet opens the existing AI Assistant provider/model controls. Subtitle Check and Subtitle Polish include enabled team rules, contextual guidelines, advisory notes, nearby cues and overlapping text from the other subtitle track. DeepSeek, OpenAI and Claude use the same saved settings and keys as the assistant. These reviews send text to the selected provider and may use multiple billed requests. Freeform chat remains available. Open Vet panel returns to the combined review workspace.

AI changes require individual approval. Changing cue text, nearby context, paired text or team policy makes pending suggestions stale. Incomplete/excerpted cues cannot receive whole-text replacements. Cancel review retains valid results from completed batches. Applied Sub A suggestions update transcript words as well as cue text; cue IDs, pinned times, Sub B text and source references are preserved. Changed word timing is estimated. The AI does not listen to audio during text vetting.

The apparent transcript copy limit was caused by reading the browser selection from a virtualized list: offscreen paragraphs were absent from the DOM. Copy now reads the underlying document. Use Copy transcript for the entire active media, or Ctrl/Cmd+A then Ctrl/Cmd+C outside text editors. Range copy uses selected word indices. There is no application character cap; browser/OS clipboard restrictions are reported instead of silently truncating. Download transcript TXT provides the complete plain text as a file. Native selection inside an editable text field is preserved.

Regression coverage includes a million-character unit case and a 16,000-word virtualized browser case, full keyboard/button copy, complete TXT download, native input selection, collapsed Find, local vet operations, mocked contextual AI vetting, policy staleness, A/B independence, transcript synchronisation and Undo. Provider tests use mocks, not paid AI requests. GitHub CI runs the complete server, frontend browser suites and Docker build.
